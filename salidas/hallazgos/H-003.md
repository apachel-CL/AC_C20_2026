# H-003 — El servicio FTP permite inicio de sesión anónimo

- **ID**: H-003
- **Evidencias**: EV-008
- **Severidad**: Media
- **Control ISO**: A.8.3
- **Certeza ISO**: Media

## Observación

[HECHO] EV-008 muestra `ftp-anon: Anonymous FTP login allowed (FTP code 230)` en 21/tcp.

## Justificación

[INFERENCIA] El acceso anónimo permite leer el contenido publicado sin identificar al usuario.

## Recomendación

- **Acción**: Deshabilitar el acceso anónimo en la configuración del servidor FTP
- **Prioridad**: P2
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo del puerto 21 no informa acceso anónimo permitido
