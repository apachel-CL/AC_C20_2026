# H-005 — Servicio distccd v1 expuesto en 3632/tcp

- **ID**: H-005
- **Evidencias**: EV-003
- **Severidad**: Alta
- **Control ISO**: A.8.9
- **Certeza ISO**: Media

## Observación

[HECHO] EV-003 muestra `3632/tcp open distccd distccd v1 ((GNU) 4.2.4 (Ubuntu 4.2.4-1ubuntu4))`.

## Justificación

[INFERENCIA] La NVD registra CVE-2004-2687 para distcc cuando no restringe qué clientes aceptan trabajos; la configuración no es visible en la evidencia (verificar).

## Recomendación

- **Acción**: Deshabilitar distccd o limitarlo a clientes autorizados con su lista de acceso y el firewall
- **Prioridad**: P1
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo no muestra 3632/tcp abierto, o la configuración muestra la restricción de clientes
