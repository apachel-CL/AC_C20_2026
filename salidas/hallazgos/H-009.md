# H-009 — Servidor web con versiones obsoletas y recursos de diagnóstico expuestos

- **ID**: H-009
- **Evidencias**: EV-009; EV-010
- **Severidad**: Media
- **Control ISO**: A.8.9
- **Certeza ISO**: Media

## Observación

[HECHO] EV-009 muestra `Server: Apache/2.2.8 (Ubuntu) DAV/2` y `X-Powered-By: PHP/5.2.4-2ubuntu5.10`; EV-010 informa Apache y PHP desactualizados, `/phpinfo.php` accesible, método TRACE activo, listado de directorios en `/icons/`, `/doc/` y `/test/`, y `/phpMyAdmin/` accesible.

## Justificación

[INFERENCIA] Las versiones visibles y las páginas de diagnóstico revelan información del sistema y amplían la superficie expuesta.

## Recomendación

- **Acción**: Actualizar Apache y PHP, retirar phpinfo.php, deshabilitar TRACE y el listado de directorios, y restringir phpMyAdmin
- **Prioridad**: P2
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo web no informa esos elementos y las cabeceras no muestran versiones obsoletas
