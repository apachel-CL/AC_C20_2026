# H-010 — Bases de datos y servicios de administración remota expuestos a la red

- **ID**: H-010
- **Evidencias**: EV-003; EV-008
- **Severidad**: Media
- **Control ISO**: A.8.20
- **Certeza ISO**: Media

## Observación

[HECHO] EV-003 muestra abiertos `3306 mysql MySQL 5.0.51a-3ubuntu5`, `5432 postgresql PostgreSQL DB 8.3.0 - 8.3.7`, `5900 vnc VNC (protocol 3.3)`, `1099 java-rmi`, `2049 nfs`, `6000 X11`, `8180 http Apache Tomcat/Coyote JSP engine 1.1` y `8787 drb Ruby DRb RMI (Ruby 1.8)`; EV-008 muestra los mismos servicios.

## Justificación

[INFERENCIA] Estos servicios no necesitan ser accesibles desde toda la red; su exposición amplía la superficie expuesta.

## Recomendación

- **Acción**: Restringir con firewall estos servicios a los equipos autorizados y deshabilitar los que no se usen
- **Prioridad**: P2
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo desde un equipo no autorizado no muestra esos puertos abiertos
