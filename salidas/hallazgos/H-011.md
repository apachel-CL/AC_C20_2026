# H-011 — El servidor SMTP habilita el comando VRFY

- **ID**: H-011
- **Evidencias**: EV-008
- **Severidad**: Baja
- **Control ISO**: A.8.9
- **Certeza ISO**: Baja

## Observación

[HECHO] EV-008 muestra `smtp-commands: metasploitable.localdomain, PIPELINING, SIZE 10240000, VRFY, ...` en 25/tcp.

## Justificación

[INFERENCIA] VRFY permite confirmar si existen cuentas de correo en el servidor.

## Recomendación

- **Acción**: Deshabilitar el comando VRFY en la configuración de Postfix
- **Prioridad**: P3
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo del puerto 25 no lista VRFY entre los comandos
