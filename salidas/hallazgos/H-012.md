# H-012 — NFS exporta el sistema de archivos raíz `/` a cualquier host

- **ID**: H-012
- **Evidencias**: EV-023; EV-022; EV-021
- **Severidad**: Alta
- **Control ISO**: A.8.3
- **Certeza ISO**: Media

## Observación

[HECHO] EV-023 (`nfs-showmount`) muestra la exportación `/ *`; EV-022 y EV-023 (`rpcinfo`) muestran `100003 2,3,4 2049/tcp nfs` y el servicio `mountd`; EV-021 muestra `2049/tcp open nfs`.

## Justificación

[INFERENCIA] Un recurso NFS que exporta el directorio raíz `/` con el comodín `*` queda disponible para cualquier equipo de la red, lo que permitiría leer o escribir archivos del sistema sin control de acceso. No se montó el recurso, por lo que el alcance efectivo no se verificó.

## Recomendación

- **Acción**: Restringir la exportación NFS en `/etc/exports` a los equipos autorizados (sin comodín `*` y sin la raíz), o deshabilitar NFS si no se usa
- **Prioridad**: P1
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo no lista la exportación `/` para todos los hosts, o `showmount -e` no la muestra
- **Comandos propuestos**: `showmount -e 192.168.56.101` (propuesto: lo ejecuta el auditor)
