# H-014 — Apache Tomcat 5.5 y el conector AJP13 expuestos en 8180/tcp y 8009/tcp

- **ID**: H-014
- **Evidencias**: EV-022; EV-021
- **Severidad**: Media
- **Control ISO**: A.8.9
- **Certeza ISO**: Media

## Observación

[HECHO] EV-022 muestra `8180/tcp open http Apache Tomcat/Coyote JSP engine 1.1`, `http-title: Apache Tomcat/5.5`, y `8009/tcp open ajp13 Apache Jserv (Protocol v1.3)`; EV-021 muestra ambos puertos `open`.

## Justificación

[INFERENCIA] Apache Tomcat 5.5 es una versión sin soporte y el conector AJP13 expuesto a la red amplía la superficie de ataque del servidor de aplicaciones; su exposición a toda la red no es necesaria para la operación del laboratorio.

## Recomendación

- **Acción**: Actualizar o retirar Apache Tomcat 5.5 y restringir el conector AJP (8009/tcp) con firewall a los equipos autorizados, o deshabilitarlo si no se usa
- **Prioridad**: P2
- **Responsable sugerido**: Administrador del sistema
- **Criterio de cierre**: Un nuevo escaneo no muestra Tomcat 5.5 ni el conector AJP13 expuestos, o muestra una versión vigente con el conector restringido
- **Comandos propuestos**: `nmap -sV -p8009,8180 192.168.56.101` (propuesto: lo ejecuta el auditor)
